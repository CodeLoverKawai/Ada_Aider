**Goal:** Create 13 university-level academic skills for Systems Engineering and Computer Science, update system indexes (`GEMINI.md`, `README.md`), and verify all test suites.

**Architecture:** Create each skill in `skills/<skill-name>/SKILL.md` with complete pedagogical and technical depth, KaTeX formulas, Mermaid diagrams, GFM tables, and AFFiNE note templates. Register them in the dynamic routers and update the total skill count to 67.

- Every skill must have valid YAML frontmatter with `name` and third-person `description` starting with `Use when...`.

- Include comprehensive quick reference tables, core mathematical/architectural models, practical examples, and AFFiNE note integration.
- Update `GEMINI.md` and `README.md` catalog with all 13 skills.
